How it works

Your answers, not a guess.

The chatbot matches each question to the business’s own FAQ answers using keywords and fuzzy matching, so it never makes things up.

01

Write the FAQ once

Hours, prices, bookings, parking: the questions customers ask every day, answered in the owner’s own words.

02

Customers just ask

Questions are matched by keyword with typo tolerance (“opne sunday?” still works). Quick-reply chips help too.

03

Leads come to you

When someone wants a booking or a human, it collects their name and contact details for a callback.

Features

Small, fast, and free to run.

No monthly fees

Runs in the visitor’s browser. No API keys, no per-message costs.

Only approved answers

Every reply comes from the owner’s FAQ list, so there are no hallucinations.

Lead capture

Collects name, phone or email and a note for bookings and callbacks.

One-line install

Drops into any existing website: WordPress, Wix, Squarespace or plain HTML.

Mobile-first

Quick-reply chips and a thumb-friendly layout for customers on their phones.

Upgradeable

Can later be connected to a free-tier AI model for open-ended questions, if wanted.

ⓘ
This is a demo of a zero-cost website FAQ chatbot. The businesses (Kōwhai Corner Café, Harbour Flow Plumbing, Ponsonby Shears) are fictional and all their details are made up. Nothing you type is sent anywhere; demo “leads” are only saved in your own browser’s local storage.
